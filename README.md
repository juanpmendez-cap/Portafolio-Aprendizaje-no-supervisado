# Portafolio-Aprendizaje-no-supervisado
Portafolio de proyectos de aprendizaje no supervisado y aprendizaje automático aplicado, desarrollado en Python mediante Jupyter Notebook. El repositorio incluye análisis de reducción de dimensionalidad, clustering, sistemas de recomendación, multiple testing, reinforcement learning y análisis bioinformático aplicado a cáncer pancreático.
