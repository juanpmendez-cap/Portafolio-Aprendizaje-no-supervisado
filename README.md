# Portafolio Aprendizaje No Supervisado

Este repositorio reúne distintos proyectos desarrollados en el área de aprendizaje no supervisado y aprendizaje automático aplicado utilizando Python y Jupyter Notebook. Los proyectos incluyen análisis de reducción de dimensionalidad, clustering, sistemas de recomendación, pruebas estadísticas múltiples, aprendizaje por refuerzo y análisis bioinformático aplicado a datos reales de expresión génica.

El objetivo general del repositorio es documentar distintas metodologías de análisis de datos y aprendizaje automático, enfatizando tanto la interpretación de resultados como la exploración de patrones complejos en conjuntos de datos de distinta naturaleza.

Durante el desarrollo de los proyectos se utilizaron bibliotecas orientadas a ciencia de datos, estadística y machine learning, incluyendo:

- **pandas**
- **NumPy**
- **matplotlib**
- **scikit-learn**
- **SciPy**
- **statsmodels**
- **gymnasium**
