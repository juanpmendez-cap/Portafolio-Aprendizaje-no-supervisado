# Portafolio Aprendizaje No Supervisado

Este repositorio reúne distintos proyectos de aprendizaje no supervisado desarrollados en formato reproducible mediante Python y Jupyter Notebook. Los proyectos incluyen reducción de dimensionalidad, clustering, sistemas de recomendación, pruebas estadísticas múltiples, aprendizaje por refuerzo y análisis bioinformático aplicado a datos reales de expresión génica.

## Índice de proyectos

### [PCA y Sistemas de Recomendación](./PCA%20y%20Sistemas%20de%20Recomendación/)

Análisis de reducción de dimensionalidad mediante PCA y exploración de sistemas de recomendación.

### [Análisis de Clustering](./Análisis%20de%20Clustering/)

Implementación y comparación de modelos de clustering, incluyendo K-Means y clustering jerárquico.

### [Multiple Testing y Aprendizaje por Refuerzo](./Multiple%20Testing%20y%20Aprendizaje%20por%20Refuerzo/)

Análisis de pruebas estadísticas múltiples y entrenamiento de agentes mediante aprendizaje por refuerzo.

### [Análisis No Supervisado de Cáncer Pancreático](./Análisis%20No%20Supervisado%20de%20Cáncer%20Pancreático/)

Análisis de expresión génica en cáncer pancreático utilizando PCA, K-Means, clustering jerárquico e interpretación clínica.

## Tecnologías utilizadas

- Python
- Jupyter Notebook
- pandas
- NumPy

- scikit-learn
