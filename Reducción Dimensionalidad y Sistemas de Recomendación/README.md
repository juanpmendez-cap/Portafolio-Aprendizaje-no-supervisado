*A3.1 PCA y Sistemas de Recomendación*

En este proyecto se desarrollan distintos análisis y modelos relacionados con reducción de dimensionalidad y sistemas de recomendación utilizando técnicas de aprendizaje automático no supervisado. El objetivo principal es explorar cómo métodos como PCA y los sistemas de filtrado colaborativo pueden utilizarse para identificar patrones relevantes en conjuntos de datos de alta dimensionalidad y generar recomendaciones personalizadas.

La primera parte del proyecto se enfoca en reducción de dimensionalidad mediante Principal Component Analysis (PCA). Para ello se utilizaron conjuntos de datos de clasificación y expresión génica, analizando la proporción de varianza explicada, la representación de los datos en espacios reducidos y la utilidad de PCA para simplificar problemas con una gran cantidad de variables.

La segunda parte del proyecto aborda sistemas de recomendación, incluyendo enfoques basados en contenido y filtrado colaborativo. Se implementaron modelos capaces de identificar similitudes entre usuarios y elementos, además de analizar representaciones latentes generadas mediante técnicas de aprendizaje automático.

Durante el desarrollo se utilizaron bibliotecas de Python orientadas a ciencia de datos y machine learning, incluyendo pandas, NumPy, matplotlib y scikit-learn.
